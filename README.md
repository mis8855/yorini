# 요린이

요오드 초보도, 요리 초보도 환영해요.

방사성 요오드 치료나 검사를 앞두고 저요오드식을 하는 분이 먹으려는 음식을 입력하면, 앱에 내장된 규칙표로 먹어도 되는지(통과 · 주의 · 보류 · 확인 필요) 판정해 식단 처방전 이미지로 보여 줍니다.

- 음식 이름 입력, 성분표(원재료명) 확인
- 여러 재료로 된 요리는 가장 엄격한 재료 기준으로 판정
- 규칙표 화면에서 병원 안내문에 맞게 판정 수정 (이 기기에만 저장)
- 처방전 PNG 저장

> 이 앱은 일반적인 저요오드식 정보를 정리한 것이며, 의사의 처방이나 진료를 대신하지 않습니다. 기간과 허용 음식은 담당 병원 안내를 따르세요.
